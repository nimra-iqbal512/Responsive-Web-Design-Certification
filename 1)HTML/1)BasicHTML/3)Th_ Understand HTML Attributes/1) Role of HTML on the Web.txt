== HTML Tags Case Sensitivity
HTML tags are case-insensitive, but it is widely accepted convention and best practice to write them in lower case.

== Opening and Closing Tags OR
== Starting and Ending Tags
Each HTML tag is surrounded by a left angle bracket(<) and a right angle bracket(>). Tag name is written between these angle brackets. closing tag is differ from opening tag due to a forward slash(/).
The content is written between opening and closing tags.
<p>lorem ipsum...</p>

== Void elements: <img> (no closing tag, no content, no nested elements)
Some element don't have any content and closing tag. They just hav e closing tag.
<img>
It don't have any content or nested elements.

== Self-closing tags: <img />
sometime void elements use a '/' before '>'. Many code formatters like Prettier choose to include '/' in void elements.
<img />
The HTML spec states that the presence of the '/' does not mark the start tag as self-closing, but instead is unnecessary and has no effect of any kind
= Conclusion: Adding '/' to void elements gives no benefit, and caliing void elements as self-closing tags is informal.

== Attributes:
The 'src' attribute is use to specify the location/source of image.
Adding 'alt' in image is also a good practice. It is used to provide short, descriptive text for the image.
If the image break due to wrong location in 'src', the text written in 'alt' will be shown.

== HTML vs CSS vs JS
HTML: for content and structure
CSS: for styling
JS: for interactivity
